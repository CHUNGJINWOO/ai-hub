# AI-Hub Project Status

> Last updated: 2026-09-19

## 1. Project

AI-Hub is a personal AI engineering project that provides document and source-code ingestion, semantic/hybrid search, code-aware reranking, and MCP-based external access.

The current primary use case is searching and retrieving ROS2/LIMO project source code through the AI-Hub search system.

## Backup Automation

- PostgreSQL custom-format backup and uploaded-document archive are generated by `scripts/backup.sh`.
- Backup retention: 30 days.
- Automated execution is managed by systemd:
 - `ops/systemd/ai-hub-backup.service`
 - `ops/systemd/ai-hub-backup.timer`
 - S chedule: daily at 18:00 UTC (03:00 KST).
- Backup execution status can be checked with `journalctl -u ai-hub-backup.service`.
- PostgreSQL and uploaded-document restore procedures were separately validated.

## Service Health Checks

All core services now expose or use service-specific health checks through Docker Compose:

- PostgreSQL: `pg_isready`
- API: `GET /healthz`, including PostgreSQL connectivity check
- MCP: `GET /healthz` liveness endpoint, separate from Streamable HTTP `/mcp`
- Keycloak: `/health/ready` on the management interface, including database readiness
- All four services use `restart: unless-stopped`
